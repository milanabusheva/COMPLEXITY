## Результаты работы

Я сделала 8 итераций, на которых пыталась улучшать результаты и пробовать разные стратегии. Я пыталась всё в итоге свести к **LifeCyclePSO**.

Каждая итерация написана в папке, каждую программу можно запустить, выполнив:

```bash
./launch.sh ./<iter.name> main.cpp
```

В каждой папке в `Result.md` написан отчёт по итерации — что сделано, какие результаты наблюдаем. Были и бесполезные попытки, часть из них тоже описана. Там также приведена длина пути на каждом оцениваемом тесте и граф пути.
